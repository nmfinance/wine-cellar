# Аудит состояний (P21) — регрессионная карта

Матрица: каждый экран × три оси (пусто / офлайн / переполнено).
Проверено вживую на dev-сборке 14.08.2026: пустая база (все таблицы очищены),
вино с именем 97 символов + 15 сортов, дегустация с 30 ароматами и заметкой

## Проверено — уже было в порядке

- **Пусто.** Погреб/Wishlist/История — тексты-подсказки; статистика — нули + «Продегустируй первое вино…»; карта — «Карта наполняется сама…»; винная карта — подсказка + «0 из 10» в индикаторе сомелье; структура погреба — «+ Первый стеллаж»; профиль вкуса <3 дегустаций — только объяснение. Несуществующие id (`/wine/x`, `/tasting/x`, `/winelist/x`) — «не найдено», без белых экранов.
- **Офлайн.** Скан и анализ карты — баннеры «нужен интернет» (ошибки fetch не кэшируются — повтор при сети); AI-вопросы дегустации — карточка просто не показывается; геокодинг — откладывается с флагом и добирается при старте; бэкап — тосты об ошибке; CBR — тихий фолбэк на старый курс; Vivino в форме — состояние «unavailable». Vivino-промахи кэшируются только как `not_found`, сетевые ошибки — нет.
- **Переполнено.** Сетка/строки — `line-clamp`/`truncate`; 15 сортов — чипы переносятся; 30 ароматов — flex-wrap (просмотр) и топ-8 (статистика); вино без полей — «Год —», «Цена не указана», «не пробовал»; форма и опросник не разъезжаются.
