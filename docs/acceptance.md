# Приёмка MVP — чек-лист владельца

Проходится на телефоне (Android Chrome), на проде
https://nmfinance.github.io/wine-cellar/. Пункты с 📵 — в авиарежиме,
с 📷 — нужна камера, с 🎤 — микрофон. Отмечай по мере прохождения.

## PWA

- [ ] Установка с нуля: чистый Chrome → открыть сайт → «Добавить на главный экран» → иконка бордовая, открывается без адресной строки
- [ ] 📵 Авиарежим → открыть установленное приложение → каталог и карточки вин работают, фото на месте
- [ ] После пуша новой версии: открыть приложение → в течение минуты внизу тост «Доступна новая версия · Обновить» → тап → перезагрузка, в Настройках → О приложении версия выросла
- [ ] Тёмная тема телефона → статус-бар тёмный, приложение тёмное; Настройки → Тема → Светлая → всё мгновенно светлеет
- [ ] Нижние кнопки («Сохранить», FAB) не перекрыты жестовой полосой

## Каталог

- [ ] Погреб/Wishlist/История переключаются, счётчики совпадают с содержимым
- [ ] Поиск находит по имени и винодельне, ввод не тормозит
- [ ] Фильтры: цвет + страна + «пробовал» комбинируются; чипы снимаются
- [ ] Режим «По полкам» группирует по стеллажам, вино без места — в «Без места»
- [ ] Выпить бутылку: количество −1; последняя бутылка → вино уезжает в Историю «выпито»
- [ ] В Истории «Купил» возвращает вино в Погреб с 1 бутылкой
- [ ] Вино с длинным именем не ломает сетку (обрезается в карточках, полное на своей странице)

## Скан 📷

- [ ] Скан этикетки при хорошем свете: имя/винодельня/год/сорт распознаны, форма предзаполнена
- [ ] Рейтинг Vivino подтянулся сам (★ и число оценок), совпадает с приложением Vivino
- [ ] «Глубже о вине» появилось в карточке после сохранения
- [ ] Справка «О винодельне» появилась (для новой винодельни)
- [ ] Повторный скан ТОГО ЖЕ фото из галереи — мгновенно (кэш, без запроса)
- [ ] 📵 Скан в авиарежиме → вежливый баннер, кнопка «Вручную» работает
- [ ] Фото из галереи (не камера) тоже сканируется

## Дегустация

- [ ] Опросник: цвет → аромат → вкус → итог; балл считается на глазах
- [ ] Карточка AI-вопросов между секциями — вопросы про ЭТО вино, не общие
- [ ] 🎤 Голосовой ввод заметки работает (кнопка микрофона)
- [ ] «Вино дышит» (декантация) → плашка на главном; дозаполнение вечером работает
- [ ] После сохранения: тост с оценкой, мнение AI об оценке появляется в просмотре дегустации
- [ ] Списание бутылки из опросника (переключатель) сработало
- [ ] Оценка на карточке вина обновилась; Настройки → Оценка вина → «Лучшая» меняет бейджи

## Винная карта

- [ ] 📷 Скан карты ресторана: позиции с ценами распознаны, совет сомелье осмысленный
- [ ] 2–3 рекомендации с бейджами и причинами — первыми в списке
- [ ] Фильтры «красное/белое/до N ₽» работают
- [ ] «В Wishlist» → вино появилось в Wishlist со источником «из винной карты»
- [ ] «Дегустирую» → опросник с предзаполненным местом (название ресторана)
- [ ] История сканов открывается, сохранённые вина помечены ✓
- [ ] Индикатор «Сомелье изучает твой вкус: N из 10» растёт после дегустаций; тап показывает профиль
- [ ] После 10 дегустаций: «Сомелье-режим: персональный», рекомендации ссылаются на твои предпочтения

## Карта

- [ ] Точки виноделен на месте (цвет = твоя оценка), кластеры при отдалении
- [ ] Тап по точке → шит: вина, оценки, справка
- [ ] Пунктирное кольцо у приблизительных точек; «уточнить место» перетаскиванием работает
- [ ] Тёмная тема — тёмная карта

## Бэкап

- [ ] Настройки → Бэкап → подключение Яндекс.Диска (OAuth) проходит
- [ ] «Сделать бэкап сейчас» → на Диске в Приложениях появилась папка с db.json и фото
- [ ] Восстановление из копии на ЧИСТОМ браузере (инкогнито + вход в Яндекс) возвращает всё, включая фото
- [ ] Автобэкап: на следующий день после использования дата в настройках свежая

## Настройки

- [ ] Структура погреба: добавить/переименовать стеллаж и полки, вместимость учитывается
- [ ] Тема: все три значения; «Системная» следует за переключением темы ОС
- [ ] Оценка вина: три режима меняют бейджи каталога, карточку и цвета точек карты
- [ ] Очистить AI-кэш: размер показан; после очистки справки вин и виноделен на месте
- [ ] О приложении: версия совпадает с последним деплоем
- [ ] Статистика: цифры совпадают с реальностью (пересчитай руками «В погребе» и «Дегустаций»)

## Прочность

- [ ] Кривая ссылка (например `#/wine/abc`) → «не найдено», не белый экран
- [ ] 📵 Ни одна кнопка в авиарежиме не крутит вечный спиннер
- [ ] Телефонные жесты: пинч-зум фото в лайтбоксе, свайп между фото, системный «назад» закрывает лайтбокс/шиты, а не приложение
